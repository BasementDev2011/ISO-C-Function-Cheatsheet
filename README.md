TGC -- The Global Cheatsheet

TGC Is a project designed to document and generate an entire cheatsheet of every function. Every header. And make sure cheatsheets remain offline.
So you download it. And when the network is down and you want a function definition. You can find it right here.

It's simple to browse, using commands like grep or less are useful for browsing, or you can just use a text editor.

All is encoded in UTF-8, Ensuring portability across many devices.
