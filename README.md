TGC -- The Global Cheatsheet

TGC Is a project designed to document a lot of functions and headers ranging from C's standard library, including posix and unix additions.
Including all of the functions, every single one of them, documented,ordered and easy to use and read.

It's simple to browse, using commands like grep or less are useful for browsing, or you can just use a text editor.

All is encoded in UTF-8, Ensuring portability across many devices.

The use case for TGC is that if the day comes that networks are down. You will not be stuck trying to remember a function you don't remember.
You will be able to simply browse through TGC to look for a function you need.
